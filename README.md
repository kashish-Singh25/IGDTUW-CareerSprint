## ✨ About The Project

**IGDTUW CareerSprint** is a web-based placement preparation platform built to help students prepare for campus recruitment in a structured and accessible way.

Instead of searching across multiple websites and resources, students can explore different preparation categories from a single platform.

The platform brings together company-specific assessment resources, aptitude topics, core computer science subjects, interview questions, and career roadmaps.

## 🚀 Features

| Feature | Description |
|---|---|
| 💻 OA Questions | Company-wise online assessment preparation resources |
| 🧠 Aptitude | Quantitative aptitude, logical reasoning, puzzles and mathematics |
| 📚 CS Fundamentals | DBMS, OOPS, Operating Systems, Computer Networks and DSA |
| 🎤 Interview Preparation | Company-specific technical interview questions |
| 🗺️ Career Roadmaps | Technical and non-technical career preparation roadmaps |
| 📋 Eligibility Criteria | Access to placement eligibility resources |

## 🖥️ Platform Preview

The platform provides a simple navigation-based interface where students can select a preparation category and explore its available resources.

### Main Sections

- **Online Assessments:** Explore company-wise preparation material.
- **Aptitude:** Strengthen quantitative and logical reasoning skills.
- **Technical Preparation:** Revise essential computer science concepts.
- **Interview Questions:** Prepare for company-specific interviews.
- **Career Roadmaps:** Explore different career preparation paths.

## ⚙️ Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/kashish-Singh25/IGDTUW-CareerSprint.git
```

**2. Navigate to the project directory**

```bash
cd IGDTUW-CareerSprint
```

**3. Open the project**

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for local development.

No additional package installation is required.
